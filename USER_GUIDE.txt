1. TENTANG PROJECT DESK
================================================================================
Project Desk adalah perangkat lunak desktop personal PMO (Project Management Office)
yang dirancang untuk para Project Manager, Lead Engineer, Konsultan, dan Tim
Operasional yang membutuhkan tata kelola proyek komprehensif berstandar internasional
tanpa ketergantungan pada server cloud, langganan bulanan mahal, atau risiko kebocoran data.

Prinsip Utama Project Desk:
- 100% Offline: Seluruh data bisnis tersimpan dalam file SQLite di komputer Anda.
- Zero Cloud Leakage: Tidak ada analitik pihak ketiga atau pengiriman data ke server luar.
- Standar PMBOK 6th Edition: Integrasi penuh 10 Knowledge Areas.
- Portabilitas Penuh: Berjalan langsung dari USB Flashdisk tanpa instalasi sistem.

3. CARA INSTALASI & MENJALANKAN FILE ZIP PORTABLE
================================================================================
Format resmi rilis Project Desk v1.2.5 adalah Clean Portable ZIP (.zip).
Format ini tidak menjalankan ekstraktor dinamis sementara ke folder %TEMP%,
sehingga 100% bebas dari pemblokiran atau kecurigaan antivirus (Zero False Positive),
tidak memerlukan hak akses Administrator, dan menjaga registri sistem tetap bersih.

A. CARA MENJALANKAN DI WINDOWS (Windows 10 / 11 64-bit):
-------------------------------------------------------
1. Unduh salah satu paket ZIP dari GitHub Releases:
   - Standar   : "Project.Desk-1.2.5-win.zip" (~105 MB)
   - AI Copilot: "Project.Desk-1.2.5-AI-win.zip" (~1.3 GB)
2. Klik kanan pada file zip tersebut, pilih "Extract All..." (Ekstrak Semua).
   Pilih folder tujuan yang Anda inginkan (misalnya di "D:\Apps\ProjectDesk"
   atau langsung di dalam Flashdisk USB Anda).
3. Buka folder hasil ekstraksi, cari file "Project Desk.exe", lalu klik ganda.
4. Catatan Pertama Kali (Windows SmartScreen):
   Jika muncul jendela biru "Windows protected your PC / Microsoft Defender SmartScreen":
   - Klik tulisan "More info" (Info selengkapnya).
   - Klik tombol "Run anyway" (Tetap jalankan).
   *Hal ini wajar terjadi pada software open-source baru yang belum memiliki sertifikat
    EV komersial berbayar ribuan dolar. Aplikasi sepenuhnya aman dan bersih.
5. Selesai! Folder "project-desk-data" akan otomatis terbentuk di sebelah file exe
   sebagai tempat penyimpanan database Anda.

B. CARA MENJALANKAN DI MACOS (Apple Silicon M1 / M2 / M3 / M4 & Intel):
----------------------------------------------------------------------
1. Unduh salah satu paket ZIP dari GitHub Releases:
   - Standar   : "Project-Desk-1.2.5-arm64-mac.zip" (~118 MB)
   - AI Copilot: "Project-Desk-1.2.5-AI-arm64-mac.zip" (~1.3 GB)
2. Klik ganda file zip untuk mengekstraknya di folder Downloads atau Applications.
3. Catatan Pertama Kali (Apple Gatekeeper):
   Karena aplikasi didistribusikan langsung via GitHub tanpa langganan Apple Developer
   tahunan ($99/th), Gatekeeper mungkin menampilkan pesan:
   "Project Desk can't be opened because Apple cannot check it for malicious software".
   Cara Membuka (Cukup 1 Kali Saja):
   - Buka Finder, klik kanan (atau Control + Klik) pada "Project Desk.app".
   - Pilih "Open" (Buka).
   - Pada dialog pop-up konfirmasi, klik tombol "Open".
   - Selanjutnya, aplikasi dapat dibuka secara normal dengan klik ganda seperti biasa!

================================================================================
- Portfolio Dashboard: Menyajikan 4 Kartu KPI Agregat (Total Proyek, Progres Rata-rata %,
  Jumlah On-Track, dan Jumlah Terlambat), strip kesehatan finansial gabungan, serta

- Project Overview: Command Center untuk 1 proyek terpilih:

  * Rekonsiliasi Finansial 5 Kolom: BAC, Actual Cost (Labor + Non-Labor), EV, CV, dan CPI.
  * Strip Tata Kelola: Dampak Change Request dan verifikasi BAST dokumen deliverables.
  * Matriks Risiko 5x5 interaktif langsung di halaman depan.

7. MODUL 2: WORK BREAKDOWN STRUCTURE (WBS) & MANAJEMEN TUGAS
================================================================================
- Penomoran Otomatis Desimal: Kode WBS berjenjang (1, 1.1, 1.1.1, 1.2) dihitung otomatis.
- Tombol Aksi Hierarki:
  * Indent (Jadikan Subtask): Menjadikan tugas sebagai anak dari tugas di atasnya.
  * Outdent (Naikkan Level): Memindahkan tugas ke level hierarki yang lebih tinggi.
  * Move Up / Move Down: Menggeser urutan tugas dalam satu level.
- Kalkulasi Roll-up Summary Otomatis: Tanggal mulai, tanggal selesai, total jam kerja,
  dan persentase progres induk tugas otomatis dirangkum dari anak tugas terbawah (*leaves*).
- Penanda Milestone 0 Hari: Mengunci durasi menjadi 0d dengan ikon bendera emas.
- Penanda Unplanned: Menandai tugas dadakan di luar ruang lingkup awal tanpa merusak baseline.

================================================================================
8. MODUL 3: PENJADWALAN GANTT & CRITICAL PATH METHOD (CPM)
================================================================================
- Critical Path Method (CPM): Menghitung waktu paling awal (Early Start/Finish) dan paling
  akhir (Late Start/Finish). Tugas di jalur terpanjang memiliki Total Float = 0 hari
  dan ditandai garis merah menyala (Critical Tasks).
- Dependensi Tugas: Mendukung relasi Finish-to-Start (FS) disertai tenggat jeda (*lag days*).
- Deteksi Siklus Sirkular: Otomatis menolak relasi yang membentuk lingkaran tanpa henti (A->B->C->A).

================================================================================
9. MODUL 4: KURVA S EARNED VALUE MANAGEMENT (EVM)
================================================================================
- 3 Mode Tampilan Dinamis:
  1. Cumulative S-Curve : Grafik garis kumulatif Planned Value (PV) vs Earned Value (EV).
  2. Weekly Periodic Bar: Batang perbandingan jam kerja rencana vs realisasi per minggu.
  3. Tabular Matrix     : Tabel mingguan komprehensif lengkap dengan delta dan persentase.
- Penanda "TODAY": Garis vertikal merah membatasi realisasi aktual dengan proyeksi masa depan.
- Metrik Otomatis: Schedule Variance (SV = EV - PV) dan Schedule Performance Index (SPI).

================================================================================
10. MODUL 5: MANAJEMEN BIAYA (COST MANAGEMENT & BUDGET BASELINE)
================================================================================
- Penetapan Pagu Anggaran (Set BAC): Menetapkan pagu baseline anggaran disetujui (BAC).
- Cadangan Risiko & Overhead: Input cadangan kontingensi (%) dan markup operasional.
- Buku Besar Revisi (Revision Ledger): Setiap revisi anggaran tercatat kronologis (#1, #2, dst).
- Fleksibilitas Basis Tarif: Pilihan tarif Per Jam (Hourly), Per Hari (Daily), atau
  Biaya Borongan Tetap (Fixed Contract Cost) untuk subkontrak/vendor pihak ketiga.
- Soft Delete & Audit Trail: Menghapus transaksi biaya wajib menyertakan alasan pembatalan.
  Data tersimpan di tab "Riwayat Dibatalkan / Soft Delete" dan dapat dipulihkan kapan saja.

================================================================================
11. MODUL 6: SERVICE LEVEL AGREEMENT (SLA) & PEMELIHARAAN RUTIN
================================================================================
- Manajemen Tiket Layanan: Penanganan insiden dan tiket operasional dengan durasi SLA.
- Jeda Jam Operasional: Menghitung SLA bersih berdasarkan jam kerja kalender resmi.
- Tugas Berulang (Recurring): Penjadwalan otomatis tiket pemeliharaan preventif berkala.

================================================================================
12. MODUL 7: MANAJEMEN RISIKO & MATRIKS 5X5
================================================================================
- Siklus CRUD Lengkap: Tambah risiko baru, Edit parameter, Hapus dengan konfirmasi,
  dan ganti status cepat (IDENTIFIED, ANALYZED, MITIGATING, MONITORING, CLOSED).
- Matriks Heatmap 5x5: Memetakan probabilitas (1-5) vs dampak (1-5) ke dalam kategori
  Low (Hijau), Medium (Kuning), High (Oranye), dan Extreme (Merah).
- Nilai Moneter EMV: Expected Monetary Value = Probabilitas Numerik (%) x Dampak Biaya (IDR).

13. MODUL 8: DOKUMEN PROYEK & GERBANG FASE (LIFECYCLE GATEWAYS)
================================================================================
- Penyimpanan Tautan Cloud Aman: Menghubungkan Google Drive, SharePoint, Dropbox, GitHub.
- Verifikasi Deliverables (BAST): Menandai dokumen sebagai serah terima fisik dengan status
  DRAFT, SUBMITTED, UNDER_REVIEW, atau ACCEPTED lengkap dengan nama pihak penyetujui.

================================================================================
14. MODUL 9: KONTROL PERUBAHAN (CHANGE REQUESTS & CCB)
================================================================================
- Registrasi Permintaan Perubahan (CR): Nomor urut otomatis, ruang lingkup yang diubah,
  estimasi dampak hari (*schedule impact*), dan estimasi penambahan biaya (*cost impact*).
- Persetujuan Dewan Kontrol (CCB): Alur status PENDING -> APPROVED / REJECTED.

  (Garansi, Lisensi Lisensi Tahunan, Kontrak Sewa) dengan status Active, Warning, Expired.

21. TIPS PRAKTIS & PERTANYAAN UMUM (FAQ)
================================================================================
Q1: Apakah data saya akan hilang jika berpindah dari versi Standard ke AI Copilot Edition?
A1: TIDAK AKAN HILANG. Kedua edisi membaca file database SQLite yang sama di komputer Anda.
    Anda dapat berganti edisi kapan saja dengan sangat aman.

Q2: Mengapa di Mac muncul tulisan "Project Desk can't be opened because Apple cannot
    check it for malicious software"?
A2: Ini adalah proteksi Gatekeeper untuk aplikasi open-source tanpa sertifikat tahunan Apple.
    Solusinya: Klik kanan pada aplikasi -> pilih "Open" -> lalu klik tombol "Open" di dialog.
    Anda hanya perlu melakukan langkah ini sekali saja.

Q3: Berapa kebutuhan RAM minimum untuk menjalankan edisi AI Copilot?
A3: Minimum 8 GB RAM (Rekomendasi 16 GB RAM). Jika komputer Anda memiliki RAM 4 GB,
    sangat disarankan mengunduh Edisi Standar yang super ringan (~110 MB).

Q4: Apakah Qwen AI Copilot mengirimkan data proyek ke server OpenAI atau China?
A4: SAMA SEKALI TIDAK. Mesin Qwen di Project Desk berjalan 100% lokal (*offline on-device*).
    Tidak ada kabel jaringan atau koneksi internet yang dipakai. Data rahasia Anda tetap
    100% berada di harddisk laptop Anda.
