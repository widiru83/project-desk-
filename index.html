Cara menjalankan executable

Panduan singkat menjalankan berkas rilis v1.3.3 setelah diunduh dari GitHub Releases (semua paket .zip perlu diekstrak terlebih dahulu).

Windows (.exe / .zip)

  1. Ekstrak seluruh isi file .zip ke folder baru (jangan jalankan langsung dari dalam arsip ZIP).
  2. Klik dua kali Project Desk.exe.
  3. Jika muncul peringatan Windows SmartScreen, klik More info → Run anyway.

macOS (.app / .zip)

  1. Ekstrak file .zip, lalu pindahkan Project Desk.app ke folder Applications.
  2. Jika terblokir Apple Gatekeeper, buka System Settings → Privacy & Security → Open Anyway.
  3. Atau jalankan di Terminal: xattr -cr "/Applications/Project Desk.app" lalu buka aplikasi.

Linux (.AppImage / .zip)

  1. Ekstrak file .zip ke folder pilihan Anda.
  2. Beri izin eksekusi: chmod +x "Project Desk"*.AppImage (atau berkas binary terkait).
  3. Jalankan dengan klik dua kali atau ./Project\ Desk*.AppImage (tambahkan --no-sandbox bila diminta distro).

Chrome / Microsoft Edge Extension: pasang langsung dari Chrome Web Store, atau ekstrak .zip extension → buka chrome://extensions / edge://extensions → aktifkan Developer mode → klik Load unpacked → pilih folder hasil ekstrak.
