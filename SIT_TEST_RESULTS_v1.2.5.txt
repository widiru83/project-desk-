BAGIAN 1: PENGUJIAN PENERIMAAN MATEMATIKA & KEAMANAN DOMAIN (ACCEPTANCE TESTS)
File: tests/acceptanceTests.test.mjs — 17 Skenario Uji

[SIT-01] Aritmatika Tanggal Kalender Kerja & Tanggal Selesai Inklusif
- Domain        : Scheduling & Working Calendar
- Skenario Uji  : Menghitung durasi tugas 5 hari kerja dengan tanggal mulai Senin.
- Kriteria Lulus: Selesai tepat hari Jumat (inklusif 5 hari kerja penuh), bukan Sabtu.
- Hasil Aktual  : 5 hari kerja terhitung presisi tanpa bias timezone (Durasi: 0.55 ms).
- Status        : LULUS (PASS)

[SIT-02] Perhitungan Earliest Start dengan Dependensi Finish-to-Start (FS) + Lag
- Domain        : CPM Predecessor Calculations
- Skenario Uji  : Tugas pendahulu selesai tanggal 2026-11-06 (Jumat) dengan lag 2 hari kerja.
- Kriteria Lulus: Tugas penerus harus mulai tepat pada tanggal 2026-11-10 (Selasa berikutnya),
                  melewati akhir pekan secara tepat.
- Hasil Aktual  : Tanggal suksesor terhitung tepat sesuai kalender kerja (Durasi: 0.50 ms).
- Status        : LULUS (PASS)

[SIT-03] Deteksi Siklus Sirkular Dependensi (Circular Dependency Chain Detection)
- Domain        : Directed Acyclic Graph (DAG) Validation
- Skenario Uji  : Input dependensi sirkular yang tidak logis: Tugas A -> B -> C -> A.
- Kriteria Lulus: Sistem otomatis menolak relasi dan mengembalikan jejak rantai penyebab
                  "Detected cycle chain: A -> B -> C -> A".
- Hasil Aktual  : Siklus terdeteksi dan dihentikan sebelum merusak scheduler (Durasi: 0.15 ms).
- Status        : LULUS (PASS)

[SIT-04] Critical Path Method (CPM) Forward/Backward Pass, Float & Jalur Kritis
- Domain        : Schedule Optimization (CPM Engine)
- Skenario Uji  : Jaringan proyek 5 tugas dengan jalur paralel berdurasi berbeda.
- Kriteria Lulus: Menghitung Early Start, Early Finish, Late Start, Late Finish.
                  Tugas di jalur terpanjang memiliki Total Float = 0 (Critical Path).
- Hasil Aktual  : Jalur kritis dan float teridentifikasi secara matematis (Durasi: 0.26 ms).
- Status        : LULUS (PASS)

[SIT-05] Roll-Up Progres Berbobot Hierarkis WBS (Leaf-Only Weighting)
- Domain        : WBS Summary Roll-Up
- Skenario Uji  : Parent task dengan 2 anak (leaf) berbobot 20% dan 80%.
                  Leaf-1 selesai 100%, Leaf-2 selesai 50%.
- Kriteria Lulus: Progres parent harus tepat (20% x 100%) + (80% x 50%) = 60.0%.
                  Tidak boleh ada perhitungan ganda (double-counting).
- Hasil Aktual  : Progres parent terhitung tepat 60.0% murni dari leaf (Durasi: 0.13 ms).
- Status        : LULUS (PASS)

[SIT-06] Kurva S Berbobot Effort: Kumulatif, Varians SV, SPI & Batang Delta Mingguan
- Domain        : Earned Value Management (EVM)
- Skenario Uji  : Membentuk kurva S dari distribusi jam kerja planned vs actual log.
- Kriteria Lulus: Membagi garis waktu mingguan, menghitung PV kumulatif, EV kumulatif,
                  Schedule Variance (SV = EV - PV), dan SPI pada tanggal cut-off.
- Hasil Aktual  : Kurva S kumulatif dan batang delta mingguan terhitung akurat (Durasi: 0.20 ms).
- Status        : LULUS (PASS)

[SIT-07] Perhitungan SLA Respons & Resolusi dengan Penggabungan Jeda Tumpang Tindih
- Domain        : Operational & Maintenance Governance
- Skenario Uji  : Tiket dengan target SLA resolusi 240 menit. Ada jeda jam kerja di luar kalender
                  dan 2 periode jeda menunggu respon klien yang tumpang tindih.
- Kriteria Lulus: Jeda waktu digabungkan secara matematis (union intervals) tanpa dobel potong.
- Hasil Aktual  : Durasi bersih SLA terhitung presisi (Durasi: 0.48 ms).
- Status        : LULUS (PASS)

[SIT-08] Penjadwalan Tugas Berulang (Recurring Tasks) & Clamping Akhir Bulan
- Domain        : Preventive Maintenance Automation
- Skenario Uji  : Pola perulangan bulanan pada tanggal 31 dijadwalkan untuk Februari dan April.
- Kriteria Lulus: Tanggal 31 otomatis di-clamp menjadi 28 Februari (atau 29 pada kabisat)
                  dan 30 April tanpa error tanggal invalid.
- Hasil Aktual  : Penjepitan tanggal akhir bulan berhasil tanpa crash (Durasi: 0.09 ms).
- Status        : LULUS (PASS)

[SIT-09] Rekonsiliasi Finansial & Proyeksi EAC (Estimate at Completion)
- Domain        : PMBOK Cost Control
- Skenario Uji  : Budget 100, Incurred 30, Commitment 20, Forecast Remaining 50.
- Kriteria Lulus: EAC = Incurred + Forecast = 80. Varians Biaya = -20 (Under budget).
                  Sisa anggaran = Budget - Incurred = 70.
- Hasil Aktual  : Formula EAC dan Varians sesuai ekspektasi standar PMBOK (Durasi: 0.11 ms).
- Status        : LULUS (PASS)

[SIT-10] Pengecualian Entri Biaya Soft-Delete / Dibatalkan dari Kalkulasi Finansial
- Domain        : Cost Data Integrity
- Skenario Uji  : Membatalkan pengeluaran Rp10.000.000 dengan status CANCELLED / is_deleted = 1.
- Kriteria Lulus: Nominal Rp10.000.000 tidak boleh ikut terjumlah ke dalam total Incurred Cost.
- Hasil Aktual  : Entri dibatalkan otomatis dikeluarkan dari penjumlahan biaya (Durasi: 0.08 ms).
- Status        : LULUS (PASS)

[SIT-11] Evaluasi Sasaran Bisnis & Arah Indikator (INCREASE, DECREASE, RANGE)
- Domain        : Business Objectives & Realization
- Skenario Uji  : Evaluasi target: (a) Penjualan: INCREASE, (b) Bug: DECREASE, (c) SLA: RANGE.
- Kriteria Lulus: Status evaluasi menghasilkan MET, UNMET, atau PROGRESSING secara objektif.
- Hasil Aktual  : Formula 3 arah indikator dievaluasi dengan benar (Durasi: 0.12 ms).
- Status        : LULUS (PASS)

[SIT-12] Pelacakan Tanggal Majemuk Aset (Satu Aset, 3 Kewajiban Berbeda)
- Domain        : Asset Lifecycle Tracking
- Skenario Uji  : 1 server fisik dengan tanggal Garansi Hardware, Lisensi OS, dan Sewa Rak.
- Kriteria Lulus: Menghasilkan 3 kewajiban mandiri dengan kalkulasi status kadaluarsa masing-masing.
- Hasil Aktual  : 1 entitas aset memetakan 3 status kewajiban independen (Durasi: 0.10 ms).
- Status        : LULUS (PASS)

[SIT-13] Penilaian Risiko Probabilitas x Dampak (1-25) & Nilai Moneter EMV
- Domain        : Quantitative Risk Analysis
- Skenario Uji  : Risiko Probabilitas 4, Dampak 5. Dampak Moneter Rp100.000.000.
- Kriteria Lulus: Skor Keparahan = 20 (EKSTREM). Nilai EMV = 0.8 x Rp100.000.000 = Rp80.000.000.
- Hasil Aktual  : Skor risiko 20 dan EMV Rp80.000.000 terhitung akurat (Durasi: 0.05 ms).
- Status        : LULUS (PASS)

[SIT-14] Sanitasi Formula Injection CSV (Keamanan Ekspor Spreadsheet)
- Domain        : Data Portability Security
- Skenario Uji  : Ekspor nama tugas yang mengandung karakter berbahaya: "=cmd|' /C calc'!A0",
                  "+1234", "@SUM(A1:A10)", "-2+3".
- Kriteria Lulus: Karakter awal disanitasi dengan tanda petik tunggal (') di depannya.
- Hasil Aktual  : Injeksi formula tertangkal 100%, aman dibuka di Excel (Durasi: 0.46 ms).
- Status        : LULUS (PASS)

[SIT-15] Validasi Protokol URL Tautan Cloud (Google Drive, SharePoint, Dropbox)
- Domain        : Safe External Navigation
- Skenario Uji  : Membuka link http://, https:// vs skema berbahaya javascript://, file://, data://.
- Kriteria Lulus: Hanya http/https yang diizinkan lewat openExternalLink. Skema lain ditolak.
- Hasil Aktual  : Protokol berbahaya diblokir secara mutlak (Durasi: 1.08 ms).
- Status        : LULUS (PASS)

[SIT-16] Autentikasi Kriptografis Akun Lokal & Hashing PBKDF2
- Domain        : Local Identity & RBAC Security
- Skenario Uji  : Registrasi pengguna, pembuatan salt acak, hashing PBKDF2 100.000 iterasi,
                  dan verifikasi kunci sesi.
- Kriteria Lulus: Password salah ditolak. Percobaan berulang memicu penguncian akun (lockout).
- Hasil Aktual  : Enkripsi dan autentikasi aman teruji kokoh (Durasi: 60.10 ms).
- Status        : LULUS (PASS)

[SIT-17] Buku Catatan Aktivitas Terpadu (Unified Activity Logbook) & Soft-Voiding
- Domain        : Governance & Audit Trail
- Skenario Uji  : Pencatatan otomatis aktivitas operasional, filter 4 perspektif, dan void catatan.
- Kriteria Lulus: Entri yang di-void tidak dihapus fisik, melainkan ditandai alasan pembatalannya.
- Hasil Aktual  : Jejak audit tersimpan permanen dan tidak dapat diubah diam-diam (Durasi: 0.08 ms).
- Status        : LULUS (PASS)
