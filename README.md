## 🌟 Fitur Utama & Keunggulan

### 1. 100% Bekerja Offline & Kerahasiaan Data Mutlak (Data Sovereignty)
- **Data Tersimpan Mandiri di Komputer Anda:** Seluruh data proyek, jadwal WBS, dan catatan keuangan tersimpan langsung di perangkat lokal Anda. Data Anda dijamin aman, permanen, dan tidak akan pernah terhapus secara otomatis oleh pembersihan browser.
- **Privasi Maksimal (Nol Data ke Cloud):** Aplikasi beroperasi penuh tanpa memerlukan koneksi internet. Tidak ada satu pun data rahasia proyek, nama klien, rincian anggaran, atau aktivitas kerja yang dikirim ke server pihak ketiga maupun cloud publik.
- **Proteksi Data Otomatis:** Dilengkapi sistem penyimpanan berstandar industri yang menjaga data tetap utuh, konsisten, dan bebas dari risiko kerusakan data (*anti-corrupt*) meskipun komputer Anda tiba-tiba mati atau terputus daya listrik.

### 2. Core PMO & Advanced Scheduling Engine
- **WBS Dinamis & Deterministik:** Penomoran hierarki otomatis (`1`, `1.1`, `1.1.1`) dengan drag-and-drop dan kalkulasi roll-up hanya dari leaf tasks (mencegah double-counting durasi dan progress).
- **Critical Path Method (CPM):** Algoritma topological sort dan Forward/Backward pass untuk menghitung Earliest Start/Finish, Latest Start/Finish, Total Float, Free Float, dan mendeteksi Critical Path.
- **Deteksi Siklus Dependensi:** Mendeteksi dependensi melingkar (`A -> B -> C -> A`) secara deterministik sebelum jadwal dieksekusi.
- **Kalkulasi Hari Kerja Inklusif:** Perhitungan tanggal finish inklusif dengan kalender kerja kustom dan daftar hari libur nasional.
- **Kurva S Bobot Effort (Earned Value):** Menghitung `PV_effort(t)`, `EV_effort(t)`, `SV_effort`, dan `SPI_effort`, dilengkapi bar perbandingan mingguan serta tabel rekonsiliasi W1–Wn.
- **Baseline Berversi:** Simpan snapshot rencana (baseline) dan bandingkan varians jadwal/durasi terhadap progress riil.

### 3. Service Desk Operations & Time Tracking
- **Kanban Board 7 Status:** Kolom terstruktur (*Baru, Ditinjau, Dikerjakan, Menunggu, Verifikasi, Selesai, Dibatalkan*) dengan matriks transisi status yang divalidasi.
- **SLA Engine Multi-Timezone:** Mendukung jam kerja kalender (e.g. 08:00–17:00 WIB/UTC+7) vs 24x7, dengan kalkulasi jeda (*selective pause*) otomatis yang menggabungkan interval tumpang tindih (*overlapping intervals*) tanpa pengurangan ganda.
- **Recurring Maintenance Engine:** Penjadwalan pemeliharaan rutin (harian, mingguan, bulanan) dengan logika penjepitan tanggal 31 (*month-end clamping*) untuk bulan Februari (28/29) dan bulan 30 hari (April, Juni, September, November).
- **Native Persistent Timer:** Timer pekerjaan yang persisten di SQLite lokal. Hanya satu timer aktif per pengguna; pulih otomatis saat aplikasi ditutup/dibuka kembali; dialog konfirmasi otomatis saat dihentikan.
- **Work Logs & Rate Provenance:** Setiap jam kerja mencatat snapshot tarif efektif per jam saat pencatatan dilakukan, sehingga perubahan tarif di masa depan tidak merusak laporan biaya historis.

### 4. Cost Management & Governance
- **Tiga Mode Biaya:** *DISABLED*, *BUDGET_AND_EXPENSES_ONLY*, dan *FULL_COSTING*.
- **Estimasi Saat Selesai (EAC):** `EAC = Realisasi Biaya + Komitmen Terbuka + Sisa Perkiraan`.
- **Sisa Anggaran Setelah Komitmen:** `Sisa = Anggaran - (Realisasi + Komitmen Terbuka)`, secara ketat mencegah double-counting komitmen terbuka.
- **Kategori Biaya Fleksibel:** Tenaga kerja, perangkat keras, lisensi software, vendor eksternal, perjalanan, dan pelatihan.

### 5. Business Objectives & Benefits Realization
- **Pemisahan Output vs Outcome vs Benefit:** Menghubungkan work item ke indikator dampak bisnis nyata.
- **Indikator Berarah:** Mendukung target *INCREASE* (pendapatan, uptime), *DECREASE* (biaya, tiket insiden), dan *RANGE* (stabilitas sistem) tanpa distorsi matematika linear.
- **Perhitungan ROI Nyata:** `ROI = (Total Manfaat Finansial - Total Biaya) / Total Biaya`.

### 6. Asset & Expiry Management
- **Multi-Date Obligations:** Melacak berbagai batas waktu per aset secara bersamaan (akhir lisensi, akhir garansi, jadwal kalibrasi, batas dukungan vendor).
- **Status Otomatis:** Menurunkan status secara dinamis (*VALID*, *EXPIRING*, *EXPIRED*, *NOT_YET_VALID*, *UNKNOWN*).

### 7. Keamanan & Portabilitas Data
- **Local App Lock (PBKDF2):** Kunci aplikasi lokal opsional dengan hashing PBKDF2 (100.000 iterasi, SHA-256). Dilengkapi perlindungan brute-force (lockout 60 detik setelah 5 kegagalan berturut-turut). Kredensial tidak pernah masuk ke database workspace atau file plaintext.
- **Pemisahan Preferensi UI:** Pengaturan tipografi, slider ukuran teks, densitas tampilan, dan tema disimpan di `config/app-preferences.json` terpisah dari database bisnis.
- **Cadangan Standalone SQLite:** Fitur cadangan menggunakan SQLite `VACUUM INTO` untuk menghasilkan file `.sqlite3` mandiri yang bebas lock. Rotasi cadangan otomatis mempertahankan 7 harian dan 4 mingguan.
- **Staging Restore Aman:** Proses pemulihan database diverifikasi terlebih dahulu di direktori sementara (staging) dan membuat snapshot keselamatan sebelum melakukan swap atomik.
- **Proteksi Formula CSV (RFC-4180):** Ekspor/impor CSV terlindung dari serangan *CSV Formula Injection* dengan menambahkan prefix `'` pada karakter berbahaya (`=`, `+`, `-`, `@`, `\t`, `\r`) sambil tetap mempertahankan nilai angka sah.
- **URL Sanitization:** Tautan dokumen eksternal (Google Drive, SharePoint, GitHub, dsb.) divalidasi ketat di proses utama, hanya mengizinkan skema `http:` dan `https:`.

## 🚀 Panduan Instalasi & Ekstraksi File ZIP

### 1. Panduan Pengguna Windows (Windows 10 / 11)

1. **Unduh Berkas:**
   Unduh [`Project.Desk-1.2.5-win.zip`](https://github.com/widiru83/project-desk-/releases/download/v1.2.5/Project.Desk-1.2.5-win.zip) dari [Halaman Rilis GitHub](https://github.com/widiru83/project-desk-/releases).
2. **Ekstrak Berkas ZIP:**
   - Klik kanan pada file `Project.Desk-1.2.5-win.zip`.
   - Pilih menu **Extract All...** (Ekstrak Semua).
   - Tentukan folder tujuan (misalnya di `D:\Apps\Project Desk` atau `C:\Project Desk`, atau langsung di dalam USB Flashdisk).
   - Klik tombol **Extract**.
3. **Membuat Shortcut (Disarankan):**
   - Buka folder hasil ekstraksi.
   - Cari file `Project Desk.exe`.
   - Klik kanan `Project Desk.exe` -> pilih **Show more options** -> **Send to** -> **Desktop (create shortcut)**.
4. **Menjalankan Aplikasi:**
   - Klik ganda pada `Project Desk.exe` (atau shortcut di desktop).
   - **Catatan Windows SmartScreen:** Jika muncul layar biru *"Windows protected your PC"* (karena aplikasi ini dirilis secara open-source tanpa sertifikat EV komersial berbayar), cukup klik tautan **More info** (Info selengkapnya), lalu klik tombol **Run anyway** (Tetap jalankan). Peringatan ini hanya muncul satu kali pada peluncuran pertama.
5. **Data & Database:**
   - Seluruh data proyek dan pengaturan tersimpan lokal di `%APPDATA%\WIDIRU STUDIO Project Suite\data\workspace.sqlite3`.

---

### 2. Panduan Pengguna macOS (Apple Silicon M1/M2/M3/M4)

1. **Unduh Berkas:**
   Unduh [`Project-Desk-1.2.5-arm64-mac.zip`](https://github.com/widiru83/project-desk-/releases/download/v1.2.5/Project-Desk-1.2.5-arm64-mac.zip) dari [Halaman Rilis GitHub](https://github.com/widiru83/project-desk-/releases).
2. **Ekstrak Berkas ZIP:**
   - Klik dua kali (double-click) pada file `Project-Desk-1.2.5-arm64-mac.zip` di Finder.
   - Aplikasi pengarsip bawaan macOS (*Archive Utility*) akan mengekstrak file menjadi bundel aplikasi bernama **`Project Desk.app`**.
3. **Pindahkan ke Folder Applications:**
   - Geser (*drag and drop*) file **`Project Desk.app`** ke dalam folder **`/Applications`** (Aplikasi).
4. **Membuka Pertama Kali (Proteksi Apple Gatekeeper):**
   Karena aplikasi didistribusikan di luar Mac App Store, proteksi keamanan bawaan Apple Gatekeeper akan memverifikasi aplikasi saat pertama kali dibuka. Pilih salah satu cara mudah berikut:
   - **Cara 1 (Paling Mudah — Klik Kanan):**
     1. Buka folder `/Applications` di Finder.
     2. **Klik kanan** (atau tahan tombol `Control` lalu klik) pada icon **Project Desk.app**.
     3. Pilih menu **Open** (Buka).
     4. Pada dialog konfirmasi yang muncul, klik tombol **Open** sekali lagi.  
     *(Langkah ini hanya perlu dilakukan satu kali. Setelahnya, Anda cukup klik ganda seperti biasa).*
   - **Cara 2 (Lewat System Settings):**
     1. Jika Anda mengklik ganda dan muncul dialog *"Project Desk cannot be opened because the developer cannot be verified"*, klik **Cancel**.
     2. Buka **System Settings (Pengaturan Sistem)** -> pilih menu **Privacy & Security (Privasi & Keamanan)**.
     3. Gulir ke bawah hingga bagian **Security**, Anda akan melihat pemberitahuan: *"Project Desk was blocked from use because it is not from an identified developer"*.
     4. Klik tombol **Open Anyway (Tetap Buka)**, lalu masukkan password / Touch ID Mac Anda.
   - **Cara 3 (Via Terminal untuk Advanced User):**
     Jalankan satu baris perintah berikut di Terminal untuk menghapus atribut karantina unduhan internet:
     ```bash
     xattr -cr "/Applications/Project Desk.app"
     ```
5. **Data & Database:**
   - Database tersimpan secara lokal dan otomatis di `~/Library/Application Support/WIDIRU STUDIO Project Suite/data/workspace.sqlite3`.
